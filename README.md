# JavaScript REST API Client

## Project Overview

This project demonstrates a modular JavaScript application that consumes a REST API using the Fetch API. It loads user data, supports searching, caches results in localStorage, and displays information in a responsive interface.

## Features

- Modular JavaScript (app.js and api.js)
- Fetch API with async/await
- REST API integration
- Search users by name
- Error handling
- Loading indicator
- localStorage caching
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- JSONPlaceholder REST API

## How to Run

1. Open the project in VS Code.
2. Start Live Server.
3. Click **Load Users**.
4. Search users using the search box.
